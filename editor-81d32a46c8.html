¿Cómo creo la clave de GitHub?
  1. En github.com, entra en tu foto → Settings → abajo del todo Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Ponle un nombre ("Editor cartas") y una caducidad (por ejemplo, 1 año).
  4. En Repository access elige Only select repositories → nuestras-cartas.
  5. En Permissions → Repository permissions, busca Contents y ponlo en Read and write.
  6. Pulsa Generate token, cópialo (empieza por github_pat_) y pégalo aquí.

Cómo funciona: cambia lo que quieras y se guarda solo en este navegador. Cuando acabes, pulsa Generar álbum y se descargará index.html (ya con el nombre listo para GitHub), que es lo que le das a él. Ese archivo va cifrado: sin el código de cada sobre no se puede ver nada.
Stats: escríbelas así, separadas por " · " y con el valor al final: Calorcito 90 · Amor ∞. El valor puede ser un número, ∞ o ???.
Fotos: pulsa "Foto" en cada carta para poner la tuya en lugar del dibujo.
